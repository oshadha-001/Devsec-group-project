# Minura IT24104168 command injection and security pipeline

The original DNS Lookup page concatenates target_host into shell_exec("nslookup " . input) at security level 0. Shell metacharacters can run additional commands. CWE-78 maps to elevation and tampering, with risk 9 because the page is directly reachable and code runs with web-service privileges.

The patch replaces the shell invocation with GroupDns::resolve. Literal valid IPv4/IPv6 addresses are returned directly; bounded valid hostnames use PHP gethostbynamel. Inputs that are arrays, oversized, empty or invalid domain syntax are rejected. No shell is called. Output is HTML encoded. Hostname resolution still depends on available DNS; localhost and literal IP positive checks work offline. This implementation reports IPv4 address records for hostnames; it does not claim a full nslookup replacement or public DNS availability offline.

In the original local lab at security level 0, submit `127.0.0.1; printf GROUP-CMD-PROOF`. Capture the marker in command output. On the fixed page submit exactly the same value; expect rejection and no executed marker. The raw input appearing in a heading is not execution proof. Also test 127.0.0.1, ::1 and localhost.
